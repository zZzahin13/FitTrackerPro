# Fit Tracker Pro

Android fitness and workout tracker built with Java, Firebase Auth, and Firestore.

## Features (in progress)
- Firebase email login and registration
- Dashboard with daily stats
- Workout history (RecyclerView + Room)
- Foreground service step tracking
- Broadcast receivers and a content provider

## Setup
1. Clone the repo
2. Create a Firebase project and add `google-services.json` to the `app/` folder
3. Enable Email/Password sign-in in Firebase Authentication
4. Run on an emulator or device
